华农·智控温室监控系统（Windows x64）
========================================

启动方法
--------
1. 将压缩包完整解压到任意文件夹。
2. 双击 start.bat。
3. 程序启动后会自动打开浏览器，访问地址：
   http://127.0.0.1:8080/

运行要求
--------
- Windows 10 或 Windows 11 64 位系统。
- 无需安装 Node.js、npm 或 Go。
- 请保持 greenhouse-server.exe、web 文件夹和 start.bat 位于同一目录。

停止方法
--------
系统服务会在一个最小化的“Huanong Zhikong Server”窗口中运行。
关闭该窗口即可停止服务。

常见问题
--------
1. 启动超时：检查本机 8080 端口是否已被其他程序占用。
2. 页面无法打开：确认杀毒软件或防火墙没有阻止 greenhouse-server.exe。
3. 数据说明：当前展示数据为内置演示数据；真实传感器和模型需要配置相应 API。
